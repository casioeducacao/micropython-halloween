# Histórico de alterações

## Versão inicial preparada para publicação

- Organização da coleção Halloween matemático;
- Renomeação de `hallow 1.py` para `abobora.py` e adoção de importações explícitas;

A publicação e a atribuição de uma versão de lançamento ficam a cargo dos mantenedores.
